
## Project Customization

I adapted the ETLV processing to investigate healthy life expectancy using the 2020 World Happiness dataset.

I kept the **Extract / Transform / Verify / Load** structure and changed the CSV analysis from the overall Ladder score to the **Healthy life expectancy** column.

This allowed me to compare expected healthy lifespan across countries while continuing to use the same professional data-processing workflow.
